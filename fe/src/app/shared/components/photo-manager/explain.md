# 📂 `photo-manager/` — Gestor de Fotos

Componente para **subir, previsualizar y eliminar fotos** de productos. Soporta múltiples imágenes, muestra previsualizaciones (thumbnails) de las fotos cargadas, y permite marcar fotos existentes para eliminación. Se usa en los formularios de creación/edición de productos del admin. Interactúa con `ApiPhotoService` para la subida al backend.
