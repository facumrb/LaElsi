# 📂 `buttons/` — Botones Reutilizables

## ¿Qué es esta carpeta?

Colección de **componentes de botón** estilizados y especializados que se usan en toda la aplicación.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `close-modal-button/` | Botón cerrar modal | Botón con ícono "X" para **cerrar modales** y diálogos. |
| `filter-button/` | Botón de filtro | Botón para **abrir/cerrar** el panel de filtros en los listados. |
| `go-back-button/` | Botón volver | Botón "← Volver" que navega a la **página anterior** usando el historial de navegación. |
| `password-toggle-button/` | Toggle de contraseña | Botón con ícono de **ojo** para mostrar/ocultar la contraseña en campos de input. |
