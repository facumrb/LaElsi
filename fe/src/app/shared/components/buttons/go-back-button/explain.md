# 📂 `go-back-button/` — Botón Volver

Componente de **botón "← Volver"** que navega a la página anterior. Usa `NavigationHistoryService` para determinar si hay una ruta previa en el historial interno de la SPA, y `Location.back()` para navegar. Se usa en formularios, páginas de detalle y otras vistas secundarias.
