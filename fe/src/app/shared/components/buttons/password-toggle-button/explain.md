# 📂 `password-toggle-button/` — Toggle de Contraseña

Componente de **botón con ícono de ojo** que alterna la visibilidad de un campo de contraseña entre texto plano y oculto (`type="password"` ↔ `type="text"`). Se usa en todos los formularios que incluyen campos de contraseña (login, registro, edición de perfil, ABM de usuarios).
