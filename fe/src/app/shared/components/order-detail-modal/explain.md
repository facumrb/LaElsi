# 📂 `order-detail-modal/` — Modal de Detalle de Pedido

Componente de **modal** (ventana emergente) que muestra el detalle completo de un pedido. Incluye: datos del cliente (nombre, email, teléfono), lista de productos con cantidad y precio, método de entrega, método de pago, monto total, y estado del pedido. Se usa tanto en el admin (gestión de pedidos) como en el perfil del cliente (historial de pedidos).
