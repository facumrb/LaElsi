# 📂 `register-page/` — Página de Registro

Página con el **formulario de registro** de nuevos clientes (ruta `/auth/register`). Incluye campos para datos personales (nombre, apellido, DNI, teléfono), credenciales (email, username, contraseña, confirmar contraseña) y opcionalmente datos de dirección y facturación. Usa validaciones síncronas y asíncronas (unicidad de email, username, DNI).
