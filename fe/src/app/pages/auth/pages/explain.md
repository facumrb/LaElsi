# 📂 `pages/` — Páginas de Autenticación

## ¿Qué es esta carpeta?

Contiene las páginas individuales del módulo de autenticación.

## Subcarpetas

| Carpeta | Página | Descripción |
|---|---|---|
| `login-page/` | Iniciar Sesión | Formulario con campos de usuario/email y contraseña. Incluye validaciones y manejo de errores. |
| `register-page/` | Registro | Formulario completo para crear una cuenta de cliente. Incluye datos personales, dirección, validaciones asíncronas de unicidad (email, username, DNI). |
