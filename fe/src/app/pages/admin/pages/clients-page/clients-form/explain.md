# 📂 `clients-form/` — Formulario de Cliente

Formulario reactivo para **crear o editar** un cliente. Incluye secciones de datos personales (nombre, apellido, DNI, teléfono, email, username), dirección (calle, número, ciudad, provincia, CP, piso, depto), facturación (CUIT, condición fiscal), y contraseña. Validaciones síncronas y asíncronas.
