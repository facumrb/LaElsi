# 📂 `clients-page/` — Página de Gestión de Clientes

Página de **ABM de clientes** (ruta `/admin/clients`).

## Estructura

| Carpeta/Archivo | Función |
|---|---|
| `clients-page.component.ts/html` | Componente padre con lógica de la página. |
| `clients-toolbar/` | Barra con título, buscador y botón "Crear cliente". |
| `clients-list/` | Tabla con la lista de clientes (nombre, email, teléfono, dirección, estado, acciones). |
| `clients-form/` | Formulario para **crear o editar** un cliente. Incluye datos personales, dirección, facturación y credenciales. |
