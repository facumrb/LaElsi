# 📂 `components/` — Subcomponentes del Toolbar de Categorías

Componentes específicos del toolbar de la página de categorías.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `categories-filter-button/` | Botón de filtro | Botón para activar/desactivar filtros específicos de categorías. |
| `categories-order-modal/` | Modal de ordenamiento | Modal para **reordenar** las categorías (definir el orden en que se muestran en el e-commerce). |
