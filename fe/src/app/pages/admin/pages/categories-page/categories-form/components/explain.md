# 📂 `components/` — Subcomponentes del Formulario de Categoría

Componentes auxiliares específicos del formulario de creación/edición de categorías.

## Subcarpeta

| Carpeta | Componente | Función |
|---|---|---|
| `category-parent-select/` | Selector de categoría padre | Select para elegir una **categoría padre**, permitiendo crear jerarquías de categorías (ej: Librería > Cuadernos). |
