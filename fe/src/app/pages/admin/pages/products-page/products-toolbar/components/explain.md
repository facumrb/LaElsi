# 📂 `components/` — Subcomponentes del Toolbar de Productos

Componentes específicos del toolbar de la página de productos.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `bulk-price-modal/` | Modal de ajuste de precios masivo | Modal para **actualizar precios en lote**: permite aplicar un porcentaje de aumento/descuento a múltiples productos simultáneamente. |
| `products-filter-button/` | Botón de filtro de productos | Botón para activar filtros sobre la lista de productos (ej: por estado, categoría, stock). |
