# 📂 `components/` — Subcomponentes del Formulario de Producto

Componentes auxiliares específicos del formulario de creación/edición de productos.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `photo-manager/` | Gestor de fotos del producto | Componente para **subir, previsualizar y eliminar** las fotos del producto dentro del formulario. |
| `product-category-select/` | Selector de categoría | **Select/dropdown** para elegir la categoría a la que pertenece el producto. |
