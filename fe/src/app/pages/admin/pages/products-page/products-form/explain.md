# 📂 `products-form/` — Formulario de Producto

Formulario reactivo para **crear o editar** un producto. Campos: nombre, descripción, marca, precio, stock, estado, categoría (select), y gestión de fotos (usando `PhotoManagerComponent`). Soporta el sistema de **borradores** (`ProductDraftService`) para preservar datos al navegar temporalmente fuera del formulario.
