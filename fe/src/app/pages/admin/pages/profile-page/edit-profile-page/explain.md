# 📂 `edit-profile-page/` — Editar Perfil del Administrador

Página con un **formulario reactivo** para que el administrador edite su propio perfil (ruta `/admin/edit-profile`). Permite actualizar nombre, apellido, teléfono, email, username, foto de perfil y contraseña. Requiere verificación de contraseña actual para cambios sensibles.
