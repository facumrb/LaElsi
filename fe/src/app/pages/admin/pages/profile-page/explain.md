# 📂 `profile-page/` — Perfil del Administrador

Contiene las páginas para que el administrador logueado pueda **ver y editar su propio perfil**.

## Subcarpetas

| Carpeta | Ruta | Descripción |
|---|---|---|
| `view-profile-page/` | `/admin/view-profile` | Página de **vista** del perfil: muestra los datos del admin en modo lectura (nombre, email, foto, etc.). |
| `edit-profile-page/` | `/admin/edit-profile` | Página de **edición** del perfil: formulario para actualizar datos personales, foto y contraseña del admin. |
