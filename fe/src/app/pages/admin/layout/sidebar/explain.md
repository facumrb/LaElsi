# 📂 `sidebar/` — Menú Lateral del Admin

## ¿Qué es esta carpeta?

Contiene el componente del **sidebar (menú lateral)** del panel de administración.

## Archivos

- `sidebar.component.ts` — Lógica del sidebar (links activos, estado abierto/cerrado).
- `sidebar.component.html` — Template HTML con los ítems de navegación.

## Funcionalidad

- Lista de **links de navegación** a las secciones del admin: Analíticas, Productos, Categorías, Clientes, Administradores, Pedidos.
- Resalta la **sección activa** actual.
- Responsive: se puede colapsar en pantallas pequeñas.
