# 📂 `navbar/` — Barra de Navegación del Admin

## ¿Qué es esta carpeta?

Contiene el componente de la **barra de navegación superior** del panel de administración.

## Archivos

- `navbar.component.ts` — Lógica del componente (usuario actual, logout, toggle del sidebar).
- `navbar.component.html` — Template HTML con el diseño de la barra superior.

## Funcionalidad

- Muestra el **nombre del usuario** administrador logueado.
- Botón para **cerrar sesión** (logout).
- Botón para **abrir/cerrar el sidebar** en dispositivos móviles.
- Link al **perfil** del administrador.
