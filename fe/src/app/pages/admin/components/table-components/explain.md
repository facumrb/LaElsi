# 📂 `table-components/` — Componentes de Tabla del Admin

## ¿Qué es esta carpeta?

Agrupa los componentes reutilizables que se usan dentro de las **tablas de datos** del panel de administración.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `entity-state-badge/` | Badge de estado | Muestra un **badge visual** con el estado de la entidad (ej: "Activo" en verde, "Inactivo" en rojo). Reutilizable para productos, usuarios, etc. |
| `table-actions/` | Acciones de tabla | Botones de **acción por fila** en las tablas: Editar, Eliminar, Restaurar, Ver detalle. |
| `table-empty-state/` | Estado vacío | Mensaje que se muestra cuando una tabla **no tiene datos** (ej: "No se encontraron productos"). |
