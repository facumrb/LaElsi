# 📂 `components/` — Componentes Reutilizables del Admin

## ¿Qué es esta carpeta?

Contiene componentes **exclusivos del módulo admin** que se reutilizan en varias páginas del panel de administración. Son piezas de UI específicas para la gestión de datos.

## Subcarpetas

| Carpeta | Componente | Uso |
|---|---|---|
| `audit-info/` | Información de auditoría | Muestra las fechas de creación (`createdAt`), última modificación (`updatedAt`) y eliminación lógica (`deletedAt`) de cualquier entidad. |
| `table-components/` | Componentes para tablas | Piezas reutilizables para las tablas de datos del admin (badges de estado, acciones, estado vacío). |
| `toolbar-components/` | Componentes para toolbars | Elementos de la barra de herramientas superior de cada página (botón crear, buscador, título). |
