# 📂 `create-entity-button/` — Botón de Crear Entidad

Componente de **botón estilizado** "Crear nuevo [entidad]" que aparece en la toolbar de cada página del admin. Al hacer clic, navega al formulario de creación correspondiente (ej: `/admin/products/create`). Recibe como input el texto del botón y la ruta de destino.
