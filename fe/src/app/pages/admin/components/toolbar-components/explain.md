# 📂 `toolbar-components/` — Componentes de Toolbar del Admin

## ¿Qué es esta carpeta?

Agrupa los componentes reutilizables para la **barra de herramientas** (toolbar) que aparece en la parte superior de cada página del admin.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `create-entity-button/` | Botón de crear | Botón estilizado "Crear nuevo [entidad]" que navega al formulario de creación. |
| `search-input/` | Input de búsqueda | Campo de texto para **buscar/filtrar** los datos de la tabla por nombre u otros criterios. |
| `toolbar-title/` | Título de la página | Muestra el **título** de la sección actual (ej: "Productos", "Categorías"). |
