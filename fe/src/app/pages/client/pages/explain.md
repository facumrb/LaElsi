# 📂 `pages/` — Páginas del E-commerce

## ¿Qué es esta carpeta?

Contiene todas las **páginas individuales** de la tienda online de LaElsi.

## Subcarpetas

| Carpeta | Ruta | Descripción |
|---|---|---|
| `main-page/` | `/` | **Página principal** (home). Muestra productos destacados, categorías, banners promocionales. |
| `category-page/` | `/category/:id` | Productos filtrados por una **categoría** específica con paginación y filtros. |
| `product-page/` | `/product/:id` | **Detalle de un producto**: galería de fotos, descripción, precio, botón de agregar al carrito. |
| `cart-page/` | `/cart` | **Carrito de compras**: lista de productos seleccionados, cantidades, total, y botón para realizar el pedido. |
| `search-result/` | `/search` | **Resultados de búsqueda** con filtros y paginación. |
| `profile-page/` | `/profile` | **Perfil del cliente** (protegido). Contiene subpáginas para ver datos, editar datos y ver pedidos. |
| `impresiones-page/` | `/impresiones` | Página de servicios de **impresión**. |
| `sellos-page/` | `/sellos` | Página de servicios de **sellos**. |
| `diseno-grafico-page/` | `/disenio` | Página de servicios de **diseño gráfico**. |
| `footer-pages/` | `/about-us`, `/faq` | Páginas informativas: Acerca de nosotros y Preguntas frecuentes. |
