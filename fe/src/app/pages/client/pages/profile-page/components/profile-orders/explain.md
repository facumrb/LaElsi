# 📂 `profile-orders/` — Historial de Pedidos del Cliente

Componente que muestra el **historial de pedidos** del cliente (ruta `/profile/orders`). Lista todas las órdenes realizadas con su estado (Pendiente, Pagado, Enviado, Entregado, Cancelado), monto total, fecha y opción de ver el detalle completo del pedido en un modal.
