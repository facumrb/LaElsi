# 📂 `components/` — Componentes Reutilizables del E-commerce

## ¿Qué es esta carpeta?

Contiene componentes **exclusivos del módulo client** que se reutilizan en varias páginas de la tienda online.

## Subcarpetas

| Carpeta | Componente | Función |
|---|---|---|
| `product-card/` | Tarjeta de producto | **Card visual** de un producto con imagen, nombre, precio y botón de agregar al carrito. Se usa en catálogos y búsquedas. |
| `add-to-cart-control/` | Control de carrito | Componente con botón "Agregar al carrito" y selector de **cantidad** (+/-). |
| `breadcrumbs/` | Migas de pan | Navegación jerárquica (ej: `Inicio > Categoría > Producto`) para orientar al usuario. |
| `carousel-nav/` | Navegación de carrusel | Controles de **navegación** (flechas, indicadores) para carruseles de imágenes. |
| `products-filter/` | Filtro de productos | Panel con filtros para refinar la búsqueda de productos (precio, marca, estado, etc.). |
| `product-status-badge/` | Badge de estado | Badge visual que indica si un producto está **disponible** o **sin stock**. |
